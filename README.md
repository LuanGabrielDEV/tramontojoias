# Tramonto Joias e Semijoias

Página de links (linktree) do Instagram [@semijoiasdamile](https://www.instagram.com/semijoiasdamile).

- `index.html`: página única, sem build
- `assets/pecas/`: fotos da coleção Jardim Brilhante
- `assets/catalogo-tramonto-2026.pdf`: catálogo completo

Para mudar uma peça ou preço, edite a lista `pecas` no fim do `index.html`.
Cada push na `main` publica automaticamente no Vercel.
